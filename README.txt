Haleema's Looks v1.0

Upload all files in this folder to the root of a GitHub Pages / Cloudflare Pages / Vercel static website. No environment variables, SQL or backend required.

On iPhone: open the deployed HTTPS site in Safari, tap Share > Add to Home Screen.

IMPORTANT: All outfits and photos are stored locally using IndexedDB in the browser / installed web app. Storage is device/browser specific, may be deleted by iOS or the user, and does not automatically sync. Use Settings > Export ZIP backup regularly and save the ZIP to iCloud Drive or another safe location. The ZIP is not encrypted. Restore from Settings > Import ZIP. Import replaces existing looks. Export ZIPs from this app use the ZIP 'store' method and can be opened by standard archive tools.
